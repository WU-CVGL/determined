.. note::
    
    When deploying locally, the system prompts you to set a strong password.

    The repository install command above builds this fork's ``determined`` library and command-line
    interface (CLI) from ``harness``. A moving ``main`` checkout derives a commit-specific
    development version. Set ``VERSION=0.41.1`` only when installing the published ``0.41.1`` tag
    to pin that release's package version. This installs the CLI and SDK,
    not matching master or agent images. Historical local/cloud deployment examples may still
    select upstream image defaults and are not verified fork registry paths. See the
    :ref:`release notes <release-notes>` and the fork distribution guide before upgrading a cluster.
