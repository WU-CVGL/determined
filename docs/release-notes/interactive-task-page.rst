**Improvements**

-  WebUI: A task's page, ``/tasks/<task id>/interactive``, shows a shell's services as tabs:
   **Terminal**, **JupyterLab** and **VS Code** when the shell runs them, then the task's **Logs**
   and **Resources**. Task names, the action menu's **Open Terminal**, **Open JupyterLab** and
   **Open VS Code**, the same buttons of the **Interactive Task Launched** dialog and TensorBoard
   launches open it, and links to the old interactive and terminal pages redirect to it. **Launch
   Shell** is now **Launch Interactive Task** and **Shell Launched** is now **Interactive Task
   Launched**.
