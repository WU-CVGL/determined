**New Features**

-  WebUI: Admin → Job Privacy, a Job Privacy section in the user settings and a Sharing action on
   jobs. Jobs whose title, logs or config are not shared with the viewer show their type and ID,
   "Logs not shared" or "Config not shared".
-  CLI: Lists and descriptions print ``***`` for a title that is not shared; the config commands
   answer "Config not shared", and the logs commands end with the master's "logs not shared".
