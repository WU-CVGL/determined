**New Features**

-  WebUI: Add a **Pool Access** tab to Admin Settings. It lists each resource pool's access, granted
   users, workspace defaults, and warnings, and grants, revokes, restricts, or makes public the
   selected pools together. Grants and revocations take users, user groups, which are expanded to
   their members once when applied, and pasted usernames. See
   :doc:`/maintenance/resource-pool-access`.

-  WebUI: With basic authorization, administrators see the **Groups** tab of Admin Settings to
   create user groups and manage their members. Before, it was shown only with RBAC.
